# Tessera 跨设备 · 安卓端操作指南

手机和平板通用。Android 8.0 及以上。

---

## 1. 装好之后第一次打开

1. 系统会问**通知权限** —— 请允许。
   没有它同步照样跑，但那条"正在运行"的常驻通知不显示，出问题时你完全看不出后台在做什么。
2. 首页顶部出现**本机名字和指纹**，就说明同步服务起来了。
   如果一直显示「正在启动同步服务」超过十几秒，见本文第 7 节。

---

## 2. 和电脑配对（最常用）

1. **电脑上**：打开 Tessera → 左侧「跨设备 → 设备与同步」→ 点 **生成配对码**，出现二维码
2. **手机上**：点 **扫码配对** → 首次会请求相机权限，允许 → 把二维码放进取景框
3. 两边各自弹出一组**六位数字 + 六个表情**
4. **核对两边完全一致**，然后两边都点「一致」

完成。设备列表里会出现对方。

### 第 4 步不能跳过

设备名可以随便伪造，安全码是唯一能证明"我连上的确实是对面那台"的东西。两边显示的不一样，说明中间有人在转发——选「不一致」，配对立即作废。

### 没有摄像头 / 不方便扫码

用 **出示我的码**：手机显示自己的二维码和配对码，让对方来扫；或者让对方复制他的配对码发给你，你点 **粘贴配对码** 贴进去。

配对码**只能用一次**，60 秒过期。所以旧截图不构成风险，也没法重复使用。

### 方式三：从「附近的设备」直接点

配对区往下有 **附近的设备**，列出同一网络里还没配过的设备。点某一行的 **配对**，
对方会收到确认请求，然后照样是两边核对安全码。**不用扫码，也不用复制粘贴。**

> 每个名字下面都写着「名称未验证」，这不是啰嗦：设备名是对方自己填的，
> 谁都能把自己命名成「我的手机」。第 4 步核对安全码依然是唯一能证明身份的环节，
> 这条路径不会因为"看起来是熟悉的名字"就少一道确认。

### 列表是空的？点「扫描局域网」，别一直点「刷新」

这两个按钮做的事完全不同：

- **刷新** —— 把已经"听到"的读一遍。很多路由器会丢掉自动发现用的组播包，那种网络里刷一百次也还是空的
- **扫描局域网** —— 主动挨个问一遍。走的是普通网络流量，不依赖组播，绕开上面那个问题

**列表空着时，直接点「扫描局域网」。** 扫完每台设备下面还会显示它的 IP 地址——
两台设备地址不在同一个网段（比如一台 `192.168.1.x`、另一台 `10.0.0.x`）时，
自动发现一定失败，该走下面那条路。

### 方式四：手动输入地址（一定能连上的那条）

前面几种都不行时用它。只要两台设备之间 IP 能通就配得上，**不要求在同一个网段**，
组播被屏蔽也不影响。

点 **手动输入地址**，会打开一个对话框，上下两部分：

1. **上面是本机地址**（形如 `192.168.1.23:52140`）——念给对方，或者点「复制」发过去
2. **下面填对方的地址**——让对方在他的设备上同样打开「手动输入地址」，把他看到的那串念给你
3. 填好点 **配对**，两边照常核对安全码

> 换了 Wi-Fi 之后地址会变，所以每次打开这个对话框都会重新查一遍。
> 照着一个早就失效的地址念半天，是这条路上最常见的浪费。

### 连不上？先跑一次诊断

附近设备那张卡片最下面有 **「连不上？跑一次连接诊断」**。点它，会逐项检查并直接
告诉你卡在哪一步，每条都带一句该怎么办。

其中**主动扫描**那一项最有用：它是整份报告里唯一能区分「组播被路由器丢了」
和「对方根本不在」的检查。

## 3. 长期设备 vs 临时设备

配对时选一个：

| | 长期设备 | 临时设备 |
|---|---|---|
| 用于 | 你自己的手机、平板、电脑 | 别人的设备 |
| 自动重连 | ✅ | ❌ |
| 剪贴板互通 | ✅ | ❌ |
| 有效期 | 永久，直到你撤销 | 30 分钟 / 1 小时 / 1 天 |
| 凭据是否落盘 | 加密保存 | **完全不写进存储** |

给别人传东西就选临时——到期自动失效，不用记得回来收拾。

## 4. 日常怎么用

### 传剪贴板

**方式一**：复制内容后，打开 App 点 **发送剪贴板**。

**方式二（更快）**：选中文字 → 长按 → **分享** → 在分享列表里选 **Tessera 跨设备**。

电脑上复制的东西也会自动到达手机，直接粘贴即可。

- 长段英文、公式、特殊符号原样到达；超出系统剪贴板单次上限的超长文本，自动改用文件形式放入剪贴板，粘贴时照样是文字。
- 手机息屏断网期间电脑上复制的内容，连回来后自动补到（最近 2 分钟内的最新一条）。
- 设备列表每行后面的 **剪贴板 N ms**，是最近一次同步的实测耗时；最右边的小曲线是最近 30 次的趋势，变橙色说明网络比平时慢了一倍以上。
- **仅同步纯文本** 开关在「剪贴板自动同步」下面：打开后不带网页富格式，更快。

### 输入法模式：手机上复制即自动同步

安卓 10 起，系统只让**前台应用**和**当前默认输入法**读剪贴板。所以平时在别的应用里复制，要回到 Tessera（或点通知栏「同步剪贴板」）才能同步出去。
把 Tessera 键盘选成当前输入法之后，这条限制就不存在了：在任何应用里复制，后台立刻同步。

1. 首页剪贴板卡片里找到 **输入法模式**，点 **启用** → 在系统列表里打开「Tessera 剪贴板键盘」。
   系统会弹一段"输入法能看到你输入的内容"的标准警示：本键盘不记录、不上传任何按键，只读剪贴板里你复制的内容。
2. 回来点 **选用**，在弹出的输入法列表里选 Tessera。状态变成「正在使用」就生效了。

键盘本身是英文 + 符号键盘，顶上一条是**剪贴板时间线**：别的设备最近复制的内容点一下直接输入到当前输入框，长按放进剪贴板；左边的 ⇪ 把当前剪贴板手动发出去。
要打中文时点 🌐 切回你平时的输入法（长按 🌐 选择）——**切走之后后台就读不到剪贴板了**，这是系统规则，回到 Tessera 键盘即恢复。

### 剪贴板时间线

首页的 **剪贴板时间线** 卡片列出最近 20 条复制（电脑上能看 50 条）：本机的、别的设备同步来的、以及对方断线期间复制、连上后取回的（标「断线期间复制」）。

- **复制**：放进本机剪贴板，不再广播。
- **发给所有**：推给所有在线设备，本机剪贴板也换成它。
- **×**：从时间线移除；右上角可刷新（向在线设备重新取）或清空。
- 长文本只先取摘要，点复制时才向来源设备取正文；来源设备不在线时按钮置灰。时间线只在内存里，退出即清空，敏感内容不会进来。

### 传文件、照片、任意内容

**方式一**：App 里点 **发送文件**，在系统文件选择器里选。可以多选。

**方式二（更快）**：在相册、文件管理器、任何应用里 **长按** 要发的东西 → 点 **分享** → 选 **Tessera 跨设备**。

支持任意类型：照片、视频、APK、Word、PDF、txt、Excel、压缩包、exe 都行——它们对应用来说都只是文件。

> 收到的 `.apk` / `.exe` 一律当普通文件保存，**从不自动安装或运行**。

### 一对一还是一对多

在设备列表里**勾选**目标设备：

- 勾了若干台 → 只发给勾选的
- 一台都没勾 → 发给所有在线设备

每台设备各走各的传输，慢的不拖累快的，某一台失败不影响其他台。

### 看传输进度

传输一开始，首页就会出现一张进度卡：文件名、百分比、已传 / 总大小、对方设备名。
传完自动收起。

进度每 250 毫秒刷新一次——不是每个分块都刷，那样界面反而卡。

### 每台设备单独设置

在「已配对设备」列表里**点一下**某台设备（长按是多选删除），会弹出它的设置，选中即生效：

- **剪贴板**：全部同步 / 只同步文字（图片不收也不发） / 不同步剪贴板
- **收文件**：跟随全局设置 / 每次询问 / 自动接收

这台设备离线时，弹框顶部会写出**连不上的原因**，例如「地址通，但对方没开 Tessera」。设了「只同步文字」或「不同步」的设备，列表里状态后面会直接标出来。

### 改这台设备的名字

首页顶部本机名字旁边有个 **改名** 按钮。改完**不用重连**，已配对的设备约十秒内
就会显示新名字（名字随心跳捎带过去，不会打断正在进行的传输）。

### 收到的文件存哪

首页最下面「收到的文件存到」旁边点 **更改**，选一个你自己的文件夹（下载、图片、随便哪个）。

不选的话文件留在应用私有目录里——能用，但你在文件管理器里翻不到。**建议第一次用就设好。**

## 5. 断开之后会自己连回来

锁屏、切 Wi-Fi、进出电梯、路由器重启——都不用管。没有「重连」按钮，也不用重新扫码。

前提是那条常驻通知还在。如果被系统清掉了，说明进程被杀了，打开一次 App 即可恢复。

### 让它更可靠（国产手机建议做一次）

小米、华为、OPPO、vivo 这些系统默认会激进地杀后台。建议：

1. **设置 → 应用 → Tessera 跨设备 → 省电策略 → 无限制**（不同品牌叫法不同：「允许后台运行」「自启动」「电池优化白名单」）
2. 在最近任务列表里，把 Tessera 卡片**下拉锁定**（部分系统支持）

不做这一步不影响用，只是息屏久了可能需要重新打开一次 App。

## 6. 应用锁

**首页 → 打开应用时验证**，三选一：

| 选项 | 说明 |
|---|---|
| 不验证 | 打开即用。默认 |
| 密码 | 你自己设一个 |
| 指纹 / 面容 | 走系统的验证框，也可以用锁屏 PIN 兜底 |

指纹方式下，**应用拿不到也存不了你的指纹**——只拿到系统给的"通过了"这个结果。这是 Android 的设计，不是本应用的选择。

这个锁只管"谁能打开这个 App"，跟设备配对、跟设备之间的身份认证是**三件互不相干的事**，不共用任何密码。

## 7. 更新应用

首页往下有 **应用更新** 一段，里面是当前版本号、一个 **自动检查更新** 开关和 **检查更新** 按钮。

### 两种模式

| 模式 | 什么时候去查 |
|---|---|
| **自动检查更新（默认，开）** | 每次打开应用时在后台查一次，**只有真的有新版才会弹窗**问你 |
| 关掉开关 | 只有你按 **检查更新** 才去查 |

### 「自动」自动到哪一步

自动的只是**检查**这一步。安卓不允许一个应用悄悄替你装另一个应用——最后那次「安装」永远是**系统自己弹的框，你再点一次才真的装**。这是系统的规矩，不是本应用偷懒。

所以完整流程是：

1. 查到有新版 → 弹窗告诉你新旧版本号和安装包大小
2. 你点 **更新** 才开始下载；点 **以后再说** 就什么都不做，不下载、不留文件
3. 下载完系统弹出安装确认框
4. 你在系统框里点 **安装**，才真的装上

任何一步不点，都可以随时停下。

### 第一次会让你去开一个权限

系统要求「允许本应用安装应用」这一项打开，否则装不上。应用会在**开始下载前**就检查这一项——不会让你等完四十几兆才告诉你装不了。弹出提示时点 **去设置**，把开关打开，回来再点一次 **更新** 即可。

### 更新不会丢数据

覆盖安装保留应用内的一切：已配对的设备、设备名、应用锁、收件目录设置都还在，不用重新配对。

### 为什么可能会提示「更新源不可公开访问」

代码仓库是私有的，匿名检查拿不到版本信息，这是预期行为。这种情况下按 **检查更新** 会明确告诉你；而自动检查失败时**不会弹任何提示**——否则每次打开应用都被同一条你无能为力的错误拦一下。想看具体原因就打开故障日志（见下一节）。

## 8. 出问题时

### 一直显示「正在启动同步服务」

十几秒还不变就是启动失败了。界面上会显示具体原因。常见的是端口被占——应用会自动换端口重试，退出 App 再打开一次即可。

### 扫码后一直转圈

九成是**两台设备不在同一个局域网**。检查：

- 手机连的 Wi-Fi 和电脑是不是同一个（不是"都有网"，是同一个）
- 手机是不是在用移动数据
- 手机是不是开着自己的热点

### 明明同一个 Wi-Fi 却连不上

多半是那个网络开了 **AP 隔离**——公司、学校、酒店的 Wi-Fi 很常见，禁止同一网络下的设备互相通信。

**最快的验证和绕过办法**：

1. 手机开热点
2. 电脑连这个热点
3. 再试一次

能连上就确认是 AP 隔离。这条路走手机自己的局域网，不受路由器策略影响，日常也能一直这么用。

### 打开故障日志看具体原因

首页往下有 **故障日志** 开关，**默认关闭**。打开它，然后**再复现一次问题**，
日志里就会出现具体原因。

它只记录出问题的地方，绝不记录你的内容（剪贴板正文、文件名、路径、密钥一律不记）。
旁边的 **导出日志** 可以把它分享出来，**全选 + 删除** 可以一键清空。

### 分享菜单里找不到 Tessera

安卓的分享列表会按使用频率排序，第一次用可能要**往右滑**或点「更多」才能看到。用过一两次之后它会排到前面。

### 「附近的设备」里空着

**按这个顺序做，别跳步：**

1. **点「扫描局域网」**（不是「刷新」）。刷新只读已经听到的，路由器丢组播时永远是空的；扫描是主动问，绕开这个问题
2. **点「连不上？跑一次连接诊断」**，看它指到哪一步
3. **电脑那边看页面顶部有没有黄色横条**——写着防火墙没放行就点「一键放行」。这是电脑端最常见的原因，而且从手机这边完全看不出来
4. 还不行就用 **手动输入地址**：两台设备 IP 能通就一定配得上

另外两点：

- 已经配过的设备**不会**出现在这个列表里——它在上面的设备列表中
- 扫描后每台设备下面会显示 IP。两台地址网段不同（一台 `192.168.1.x`、一台 `10.0.0.x`）就说明不在同一个局域网，自动发现一定失败，直接走手动输入地址

### 设备显示「离线」

- 对方设备上的 Tessera 是否在运行
- 两边是否还在同一个网络
- 等 10~30 秒，发现机制会自动重扫；仍不行就两端各点一次「刷新」

## 9. 平板

界面会自动适配大屏：内容限宽居中，不会把一行文字拉到满屏宽度。横屏、分屏、折叠屏展开都能用。

其余操作和手机完全一致。

## 10. 安全上你需要知道的

- 每台设备有自己的长期密钥，首次运行时生成，存在应用私有目录里
- 用的**不是** IMEI、序列号这类硬件标识——那些撤销不了
- 在同一个网里不代表任何权限：每次连接都要重新验证配对时确认过的公钥
- 对方公钥变了会明确报警，不会悄悄接受
- 每次连接协商一次性密钥，所以录下今天的流量、日后偷到设备密钥也解不开
- 随时可以撤销任何设备，撤销立即生效
- 更新只从 github.com 下载，指向别处的下载地址会被直接拒绝
- 覆盖安装由**系统**校验签名：签名对不上的包装不上去，所以冒充不了这个应用
