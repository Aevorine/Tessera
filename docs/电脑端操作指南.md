# Tessera 电脑端操作指南

Windows 10/11 x64。这份是操作说明，照着做就行。

---

## 1. 第一次打开

装完启动后是解锁界面，默认停在 **Windows Hello** 那一页。五种方式**任意一种通过即可**进入：

| 方式 | 说明 |
|---|---|
| Windows Hello | 默认页。**人脸、指纹、PIN 都算**——弹出来的是系统自己的验证框，你在 Windows 里设了哪种就用哪种，没有指纹传感器的电脑照样可以刷脸进 |
| 密码 | 首次运行时设置 |
| 邮箱验证码 | 需先在设置里配好发件邮箱 |
| 验证器动态码 | TOTP，配好后用 Authenticator 之类的 App 生成 |
| 恢复密钥 | 一次性，用一条少一条 |

> **恢复密钥务必先存好。** 五种方式全都用不了时，它是唯一的进入途径。

### Windows Hello 什么时候弹

- **窗口一出现就弹**。从托盘点开、按 `Ctrl + Alt + T`、锁定后再切回来，每次窗口回到眼前都会重新弹一次，不用再点「验证」。
- **窗口藏在托盘里时不弹**。开机静默启动、离开时自动锁定之后，窗口看不见，验证框也不会在后台空等超时。
- 窗口被收回托盘时，正在弹的验证框会一起撤掉。

## 2. 快捷键

### 全局（应用没在前台也生效）

| 快捷键 | 作用 |
|---|---|
| `Ctrl + Alt + T` | 呼出主窗口；已经在前台时再按一次收回托盘（任务栏也不再占位） |
| `Ctrl + Shift + V` | 打开剪贴板历史面板 |
| `Ctrl + Shift + N` | 快速记一条笔记 |

这三条可以在**设置 → 快捷键**里改。故意选了生僻组合，避免抢占别的软件的常用键。如果保存后提示某条没注册上，说明被系统里其他程序占了，换一个组合即可。

### 系统级文件快捷键（接管资源管理器）

在**设置**里打开「系统级文件快捷键」之后，下面这几个键在**资源管理器里**也会走 Tessera 的高速引擎：

| 快捷键 | 作用 |
|---|---|
| `Ctrl + C` | 复制 |
| `Ctrl + X` | 剪切 |
| `Ctrl + V` | 粘贴（带进度窗，可取消） |
| `Delete` | 移入回收站 |
| `Shift + Delete` | 永久删除（会先弹确认框） |

这五条同样可以在设置里改键位。

> 这个功能由一个**独立的后台进程**提供，所以 Tessera 关掉之后它仍然生效；开机自启也是它自己的注册表项，不依赖主程序先启动。

### 应用内

不用记，菜单栏里都写着——下面这张表只是方便一次看全。

**动作**

## 2.5 菜单栏里都有什么

窗口顶部那一行。不确定某个功能藏在哪时，从这里找比在界面上翻快。

| 菜单 | 里面有 |
|---|---|
| **文件** | 新建笔记、打开文件保险箱、打开文件管理器、**最近导出**（点一下直接在资源管理器里定位到那个文件）、打开设置、系统级文件快捷键开关、隐藏到托盘、退出 |
| **编辑** | 撤销/重做、剪切/复制/粘贴、**粘贴为纯文本**（去掉网页复制带来的一身样式）、全选、删除到回收站 / 永久删除（只在文件管理面板里可点）、**命令面板** |
| **查看** | 跳到八个面板中的任意一个、**外观**（跟随系统 / 浅色 / 深色）、缩放、重新加载、全屏、设置、诊断信息 |
| **窗口** | 最小化、隐藏到托盘、**始终置顶**、**窗口居中**、**恢复默认大小**、关闭 |
| **帮助** | 操作指南、**检查更新**、**复制诊断信息**（贴给别人求助时用，里面不含你的任何数据）、项目主页、报告问题、关于 |

> **窗口跑到屏幕外面了？** 拔掉外接显示器之后很常见，这时鼠标根本够不着它。用 **窗口 → 窗口居中**，或者 **窗口 → 恢复默认大小**。

|---|---|

| **右键** | 打开下面这张菜单 |

| 项目 | 作用 |
|---|---|

| 开机静默启动（只驻留托盘） | 勾上后开机时不弹主窗口，只在托盘里待命；要用时单击托盘图标或按 `Ctrl + Alt + T` |
| 检查更新 | 同「帮助 → 检查更新」 |
| 退出 | 真正退出（关窗口只是收进托盘） |

## 3. 界面怎么用

### 找不到某个图标是干嘛的

**把鼠标停在图标上不动**，一会儿就会显示功能名称。禁用（变灰）的图标同样会显示——那恰恰是最需要知道它叫什么的时候。

工具栏上还有一个「显示文字标签」的开关（字幕图标），打开后所有图标旁边直接显示文字，不用悬停。

### 说明文字在 ⓘ 里

界面上不再铺解释性的段落。选项旁边有个小 **ⓘ** 图标的，把鼠标停在它上面就能看到这一项的详细说明（比如「完成后删除源文件」到底删多大范围）。

### 侧边导航

点左下角的折叠按钮可以把导航收成窄条只留图标。收起状态下把鼠标停在图标上会显示名称。

导航栏最下面三项是 **设置**、**故障日志**、**帮助**。故障日志平时用不到，出问题时直接点它，不用先进设置再往下找。

## 4. 跨设备：剪贴板与文件

进入左侧「跨设备 → 设备与同步」。

### 配对一台设备

1. 点 **生成配对码**，屏幕上出现二维码
2. 手机上打开 Tessera 跨设备 App，点 **扫码配对**，对准二维码
3. 两边各显示一组**六位数字 + 六个表情**
4. **核对完全一致**后，两边都点「一致」

**一共有四种配对方式**，前面连不上就往下走一种，最后一种只要两台机器 IP 能通就一定成：

| 方式 | 在哪 | 什么时候用 |
|---|---|---|
| ① 扫二维码 | 出示我的配对码 | 手机有摄像头，最快 |
| ② 复制配对码 | 出示我的配对码 → 复制配对码 | 没摄像头，把那串 `CB1:...` 发过去让对方粘贴 |
| ③ 附近设备 | 附近设备 | 同一个 Wi-Fi，列表里直接点 |
| ④ 手动输入地址 | 手动输入地址 | 上面三种都不行时的兜底 |

**③ 附近设备**——列出同一网络里还没配过的设备，点 **配对** 即可，不用扫码也不用传配对码。

列表空着的时候，**点「扫描局域网」**，不要反复点「刷新」。两个按钮做的事完全不同：

- **刷新** = 把已经"听到"的读一遍。有些路由器会丢掉自动发现用的组播包，这种情况下刷一百次也还是空的
- **扫描局域网** = 主动挨个问一遍。它走的是普通网络流量，不依赖组播，绕开了上面那个问题

**④ 手动输入地址**——最后的兜底，也是最可靠的一种。这一页上半部分显示**本机地址**（形如 `192.168.1.7:52140`），下半部分让你填**对方的地址**：

1. 在这台电脑上打开「手动输入地址」，把显示的本机地址念给对方（或点复制发过去）
2. 对方在他的设备上同样打开「手动输入地址」，把你的地址填进去，点配对
3. 两边照常核对安全码

> 两台设备只要能互相 ping 通就配得上，**不要求在同一个网段**，组播被屏蔽也不影响。
> 换了 Wi-Fi 之后地址会变，所以每次打开这一页都会重新查一遍——照着一个早就失效的
> 地址念半天，是这条路上最常见的浪费。

> 附近设备列表里每个名字都标了「名称未验证」。设备名是对方自己填的，任何人都能把自己
> 命名成「我的手机」。真正证明身份的是第 3 步那组安全码，这一步不能省。

配对时选：

- **长期设备**：自己的手机/平板/电脑。会自动重连，剪贴板互通
- **临时设备**：别人的设备。到期即失效，不自动重连，凭据不落盘

### 发送剪贴板

复制任何内容后，点 **发送剪贴板**。公式和物理符号原样到达（`E = mc²`、`m/s²`、`θ̇`），因为一次复制会同时带上纯文本、富文本、LaTeX 和图片多种形式，粘贴时由目标应用挑它认识的那种。

开着「剪贴板自动同步」时不用点按钮：复制完，另一台设备上直接粘贴。

| 情况 | 会怎样 |
|---|---|
| 长段英文 + 特殊符号（网页、PDF、Word 复制） | 纯文本与富格式合计 768 KB 以内一帧送达；更大的富格式先交付纯文本，富格式随后补齐 |
| 同一段内容隔几秒又复制一次 | 照常同步（以前会被当成重复永远丢掉） |
| 复制时对方正在断线重连 | 连回来后自动补发最近 2 分钟内的这一条；对方断线期间有更新的内容时不覆盖 |
| 手动点 **发送剪贴板** | 一定发出，对方刚收到过同样内容也照样写入 |

设备卡片上的 **剪贴板 N ms** 是最近一次同步的实测耗时：从本机发出，到对方写进剪贴板并回执。
旁边的小曲线是最近 30 次的耗时趋势；最近一次比平时慢一倍以上时整条变成橙色，网络变差一眼可见。
点开设备，右侧详情里有放大的曲线和最低 / 平均 / 最高值。

### 剪贴板时间线：翻看、再次粘贴别的设备复制过的内容

「设备与同步」里的 **剪贴板时间线** 列出最近 50 条复制：本机复制的、别的设备同步过来的，
以及对方**断线期间**复制、连上后取回的（标「断线期间复制」）。

| 按钮 | 作用 |
|---|---|
| 粘贴到本机（剪贴板图标） | 把这条放进本机剪贴板，直接 Ctrl+V。不会再广播给别的设备 |
| 发给所有设备（纸飞机图标） | 当成一次手动发送，推给所有在线设备，本机剪贴板也一起换成它 |
| 移除（×） | 从时间线删掉这一条 |
| 刷新 / 清空（右上角） | 刷新会向在线设备重新取一次；清空只清本机这份 |

- 上方可以筛「全部 / 其他设备 / 本机」，也能按内容或设备名搜索。
- 长文本（超过 64 KB）连上时只取摘要，点粘贴时才向来源设备取正文；来源设备不在线时按钮置灰。
- 时间线只在内存里，退出程序即清空；密码管理器标记的敏感内容、阅后即焚内容从不进来。
- 关掉「剪贴板自动同步」后，收到的内容不再自动写进剪贴板，但仍会出现在时间线里，需要时手动粘贴。

**选项 → 仅同步纯文本**：只同步文字与图片，不带网页、Word 里的富格式。更快，也不会把隐藏样式和链接一起带过去。

### 发送文件

有两种方式：

**方式一 —— 直接拖进来。** 从资源管理器把文件、文件夹、安装包拖到「设备与同步」面板上，松开即发送。拖动时界面会告诉你会发给谁。

**方式二 —— 点按钮。** 点 **发送文件**，在弹出的对话框里选。

两种方式的目标规则一致：

- 在设备列表里**勾选了**若干设备 → 只发给勾选的（一对一或一对多）
- **没勾选** → 发给所有在线设备

每台设备各走各的传输：慢的不拖累快的，某一台失败或拒收不影响其他台。中断后从断点续传，不用从头再来。

### 看传输进度

传输一开始，「设备与同步」面板上方就会出现一张进度卡：文件名、目标设备、百分比、
已传 / 总大小。同时传多个文件时每个一行。

进度每 250 毫秒刷新一次。之所以不是每个分块都刷：一块 4 MB，千兆网下一秒几十块，
每块都刷界面反而卡顿，250 毫秒对人眼已经是连续的。

传完或出错，这一行就从进度卡里消失，转到下面的「活动」列表里留一条记录。

### 改设备名

本机那张卡片里，设备名旁边有个铅笔图标，点它就能改。**不用重连**，已配对的设备约十秒内就会显示新名字。

### 收到的文件存哪

「选项」里「收到的文件保存到」旁边点 **更改**。选完会立刻试写一个探针文件——选到只读盘或已拔出的 U 盘会当场报错，不会等传了几个 G 才失败。

### 撤销设备

设备列表每行右边的垃圾桶图标。撤销**立即生效且不可挽回**：旧凭据在下一次连接尝试时就失效，不用等重启。

### 每台设备单独设置同步范围

点设备列表里的一台设备，右边详情里有两排按钮，选中即生效：

| 项目 | 选项 |
|---|---|
| 剪贴板 | **全部** / **只同步文字**（图片既不发给它，也不收它的） / **不同步**（连剪贴板时间线也不给它看） |
| 收文件 | **跟随全局** / **每次询问**（全局开着自动接收也要问） / **自动接收**（全局关着也直接收） |

典型用法：公司电脑设成「只同步文字」，不收家里手机的截图；家人共用的平板设成「不同步」剪贴板，文件照常互传。设置只看本机这一侧，对方不用升级。设了非「全部」的设备，列表里那一行会多一个小图标。

### 它为什么显示离线

设备离线时，详情里会多一行「连不上的原因」，比如「地址通，但对方没开 Tessera」「没有回应，多半不在同一个网络」「连上了但身份校验没过，可能要重新配对」。先照着这一行处理，再看下面的第 5 节。

换 Wi-Fi、插拔网线、电脑从睡眠醒来之后，Tessera 会在两秒内自己发现并立即重连，不用等半分钟的心跳超时。

## 4.5 文件加密：分享给别人、只校验不解密

在「文件保险箱」页面。

### 用口令加密，发给别人

1. 展开加密卡片里的「加密选项」，勾上 **口令分享**。
2. 点「加密文件」或「加密整个文件夹」，选好文件。
3. 弹出的框里设一个口令（至少 8 个字符），可以点 **生成随机口令**；下面的强度条会实时显示强弱。
4. 把 `.ivault` 文件发给对方，**口令走另一条渠道**（电话、另一个聊天软件）。

对方在自己的 Tessera 里直接「解密文件」即可，会弹框要口令。口令分享的文件**不绑定你这台电脑的身份**，所以谁拿到文件和口令都能打开；丢了口令就再也打不开。它和「后量子」档互斥，勾上口令分享后算法自动用 AES-256-GCM + Argon2id。

### 校验完整性（不解密）

解密卡片的「解密选项」里点 **校验完整性**，选一个或多个 `.ivault`。它会逐块认证并核对整体 SHA-256，**明文只在内存里经过，不写到磁盘**。结果窗口左边是完好比例的圆环，右边每个文件一行：完好 / 第几块被改动 / 文件不完整 / 校验和不符，以及算法、封装方式和校验速度。适合定期检查放在移动硬盘、网盘里的备份有没有坏。

## 5. 连不上时

### 先做这三件事，顺序别换

**第一步：看页面顶部有没有黄色横条。**

写着「Windows 防火墙没有放行 Tessera 的跨设备服务」就点旁边的 **一键放行**，会弹一次 Windows 的权限确认框，点「是」。

这是「附近的设备一直是空的」最常见的原因，而且**你自己永远猜不到**：Windows 挡掉入站连接时不报错、不记日志、也不弹窗，界面上唯一的表现就是一个空列表。只放行家庭和专用网络，公共 Wi-Fi 不放。

**第二步：点「扫描局域网」，不要反复点「刷新」。**

刷新只是把已经"听到"的读一遍；很多路由器会丢掉自动发现用的组播包，那种网络里刷多少次都是空的。扫描是主动挨个问一遍，走普通网络流量，绕开这个问题。

**第三步：点「连不上？跑一次连接诊断」。**

它会逐项检查并直接告诉你卡在哪一步，每条都带一句该怎么办：

| 这一项 | 说的是 |
|---|---|
| 监听 | 服务本身起来了没。这项红了后面都不用看 |
| 本机地址 | 有没有可用的网卡地址。只连着 VPN 时会红 |
| 局域网公布 | 自动发现的广播有没有发出去 |
| 应答端口 | 别人扫描时能不能扫到你 |
| 自动发现 | 现在被动听到了几台 |
| 主动扫描 | **这一条最有用**——它能区分「组播被路由器丢了」和「对方根本不在」 |

### 还是不行

| 现象 | 检查 |
|---|---|
| 扫码后一直转圈 | 两台设备是不是连的同一个 Wi-Fi？手机是不是连着自己的热点？ |
| 设备显示「离线」 | 电脑上 Tessera 是否在运行（托盘里能看到）？ |
| 换了 Wi-Fi 后连不上 | 等 10~30 秒会自动重新发现。仍不行就两端各点一次「刷新」 |
| 公司 / 学校 / 酒店网络 | 这类网络常开 **AP 隔离**，同一 Wi-Fi 下的设备互相不通 |
| 装了 VPN / 加速器 | 应用会自动跳过 VPN 虚拟网卡。若开了全局模式拦截局域网流量，临时关掉试试 |
| 两台设备地址网段不同 | 诊断里能看到（比如一台 `192.168.1.x`、另一台 `10.0.0.x`）。这种情况自动发现一定失败，直接用**手动输入地址** |
| 一键放行点了「否」 | 控制面板 → Windows Defender 防火墙 → 允许应用通过 → 找到 `tessera-crossdevice` 勾上「专用网络」 |

**最快的判断办法**：手机开热点，电脑连上去，再试一次。能连上就说明是原来那个网络开了 AP 隔离——这条路走的是手机自己的局域网，不受路由器策略影响。

**最后的保险**：不管什么网络，只要两台设备能互相访问，**手动输入地址**这条路一定能配上。它不依赖组播、不依赖广播、也不要求同一网段。

### 出问题时打开故障日志

导航栏里的 **故障日志**（卷轴图标，在「设置」和「帮助」之间）就是它，**设置 → 故障日志** 里也有同一份。打开开关，然后**再复现一次问题**，回到这里就能看到具体原因。

两处是同一个开关、同一份内容，从哪边开都一样。区别只是导航栏那页列表按窗口高度撑开，条目多时不用挤在一个小框里滚。

它默认关闭，只记录出问题的地方（快捷键没生效、设备连不上、服务起不来），
绝不记录你的内容——剪贴板正文、文件名、路径、密码一律不记。

看完可以全选后一键删除。

## 6. 数据在哪 / 怎么备份

**设置 → 关于** 里能看到金库的实际位置，也能点「更改位置」搬家（改完重启生效，旧目录原样保留）。

卸载**不会**删除金库。

要备份的话，整个数据目录拷走即可——里面是加密的，但请仍然妥善保管。

## 7. 在终端里用，或让 Claude Code 用

除了界面，Tessera 还能从命令行用：

```powershell
tessera status
tessera search 报销
tessera note new --title "会议纪要" --content-file .
otes.md
tessera encrypt .\合同.docx
```

同一套东西也能作为 MCP 服务器接给 Claude Code，让它直接搜笔记、建笔记、加解密文件。

**密码永远不写在命令行参数里，也不发在跟 Claude 的对话里** —— 完整说明、
工具清单和配置模板见 [Claude Code 接入](claude-code-接入.md)。
