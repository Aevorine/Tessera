> 在原需求基础上，**润色已有功能 + 增补 18 项新功能**。每项都标注：解决什么真实痛点、实现要点、所属阶段。
> 标记说明：🆕 = 原需求没有，新增；✨ = 原需求有，此处强化。

## A. 剪贴板

### A1 ✨ 多表示剪贴板（公式/符号不失真）

见架构文档 §8.2。产品侧的呈现：

粘贴时若有多种表示，长按/右键给出**格式选择器**：

```
粘贴 "E = mc²"
├ 纯文本      E = mc²
├ LaTeX      E = mc^2
├ MathML     ⟨渲染预览⟩
├ 图片       ⟨PNG 预览⟩
└ 富文本      ⟨带格式⟩
```

默认按目标应用能力自动选，但**永远允许用户手动指定**。这是"专业用户觉得好用"的关键——写论文的人明确知道自己要 LaTeX 还是 MathML。

### A2 🆕 公式识别与转换

复制到的内容如果是公式，自动补全其他表示：

| 输入形态 | 自动生成 |
|---|---|
| LaTeX 源码（检测到 `$...$`、`\frac`、`\int` 等） | MathML + 渲染 PNG + 纯文本近似 |
| MathML（从网页复制） | LaTeX + 纯文本 |
| Word 的 OMML | MathML + LaTeX |
| 纯文本里的 `E=mc^2` | 尝试解析为 LaTeX（可关闭，避免误判） |

实现：Go 侧集成轻量 LaTeX↔MathML 转换（如 `itex2MML` 规则子集），PNG 渲染在有需要时由本机字体渲染（Android 用 Canvas，Windows 用 Direct2D）。**转换失败时静默跳过，绝不破坏原始内容。**

### A3 ✨ 物理符号与单位保真

- 传输层强制 **Unicode NFC**，禁止 NFKC/NFKD（否则 `m/s²` → `m/s2`）
- 按**字素簇**切分，保证 `θ̇`（θ + 组合点）不被截断
- 附带 **符号面板**：常用物理/数学符号一键插入并发送（α β γ Δ Ω μ λ ∑ ∫ √ ∞ ≈ ≠ ≤ ≥ ± × ÷ ° ℃ Å ħ ∂ ∇ ⊗）
- 🆕 **字体缺失检测**：接收端渲染时若发现字形缺失（.notdef），提示"内容正确，本机缺字体"，并给出 PNG 表示，避免用户误以为传坏了

### A4 ✨ 跨设备剪贴板历史

```
时间线视图 · 搜索 · 收藏 · 标签 · 置顶 · 按设备筛选 · 按类型筛选
一键再复制 · 多选删除 · 自动过期（默认 7 天）· 隐私模式
```

🆕 增强项：
- **全文搜索**：SQLite FTS5，支持中文分词，10 万条内 < 50 ms
- **图片 OCR 后可搜**（本地 OCR，不上传）
- **来源应用记录**：Windows 侧可拿到源进程名（"来自 Chrome"），Android 侧标准模式下拿不到（系统限制），IME 模式下可以
- **历史仅本机**开关：默认剪贴板历史**不跨设备同步**，只同步"当前项"。想要历史同步的用户手动开——这是隐私默认值的选择

### A5 🆕 剪贴板栈 / 多槽位

高频办公痛点：要连续复制 3 段文字再依次粘贴。

```
Ctrl+Shift+C ×3  → 压入槽位 1/2/3
Ctrl+Shift+V     → 弹出面板选择槽位，或 Ctrl+Shift+1/2/3 直接粘贴对应槽位
```

槽位内容同样跨设备同步。

### A6 🆕 剪贴板转换动作

复制后一键做常见转换再发送：

```
纯文本 → 去除格式 / 去除多余换行 / 转拼音 / 简繁转换
链接   → 生成二维码 / 提取标题 / 去除跟踪参数（utm_*、fbclid…）
图片   → 压缩 / 转 PNG / 转 JPG / 去除 EXIF（含 GPS，隐私相关）
文本   → 翻译（本地/可选云端，默认关闭）
代码   → 语法高亮后作为 HTML 发送
```

### A7 ✨ 智能规则引擎

原需求已提到规则，这里给出可落地的模型：

```
WHEN  <触发>         剪贴板变化 | 收到内容 | 设备上线 | 文件到达 | 定时
IF    <条件>         来源设备 ∈ {…} ∧ 类型 = 图片 ∧ 大小 > 1MB ∧ 网络 = Wi-Fi
                    ∧ 内容匹配正则 ∧ 时间段 ∈ 09:00-18:00
THEN  <动作>         发送到设备/组 | 不同步 | 询问 | 保存到目录 | 压缩后发
                    | 打标签 | 通知 | 运行本地脚本（高危，需显式授权）
```

UI 用积木式编辑器（非代码），高级用户可切到 YAML 视图。规则**按优先级顺序匹配，第一条命中即停**，并在设置里提供"规则调试器"显示某条内容命中了哪条规则——否则规则一多用户就搞不清为什么没同步。

预置规则模板：
```
✓ 验证码不发送到临时设备
✓ 手机截图自动发到电脑
✓ 超过 100 MB 的文件禁止走移动网络
✓ 工作电脑不接收私人设备的剪贴板历史
✓ 从电脑复制的公式自动发到平板
```

### A8 🆕 剪贴板"撤回"

发出去 30 秒内可撤回，对端删除该条并从系统剪贴板清除（若仍是当前项）。
**诚实标注**：对方若已粘贴到别处，撤不回来。

## B. 文件传输

### B1 ✨ 传输队列

```
文件名 · 来源→目标 · 速度 · 已传/总量 · 剩余时间 · 网络类型 · 校验状态
[暂停] [继续] [重试] [取消] [打开所在文件夹]
```

🆕 增强：
- **全局限速** + **单任务限速**
- **优先级调整**（拖拽排序，小文件插队）
- **失败任务自动重试**（3 次，指数退避），仍失败进"待处理"列表而不是消失
- 队列**持久化**：关掉 App 再打开，任务还在，进度还在

### B2 ✨ 一对多

已在架构文档 §10.3。产品侧增补：

- 🆕 **进度聚合视图**：一行显示总体，展开看每台设备
- 🆕 **部分成功处理**：3 台成功 1 台失败 → 明确显示，并提供"只重试失败的"
- 🆕 **局域网多播加速**（第三阶段）：≥3 个接收端在同一子网时，用 UDP 多播 + FEC 纠删码分发，发送端上行只需发一遍。这在教室"老师发资料给 40 台设备"场景下是数量级的差别

### B3 🆕 传输前预检

传之前就把会失败的情况挡掉，而不是传到 90% 才报错：

```
✓ 目标设备剩余空间是否足够
✓ 目标文件系统是否支持该文件名（Windows 不允许 : * ? " < > |）
✓ 单文件是否超过目标文件系统限制（FAT32 的 4 GB）
✓ 目标目录是否可写
✓ 是否有同名文件 → 一次性询问"全部覆盖/全部跳过/全部重命名"
✓ 网络类型是否符合用户设定（移动网络大文件拦截）
```

### B4 🆕 秒传（内容去重）

发送前先发 Merkle 根。若接收端已有相同文件（曾经收过、或本来就有），直接完成，**0 字节传输**。对"反复传同一份资料给不同设备"和"重传失败任务"效果显著。

### B5 🆕 文件投递箱（增强原需求）

每台设备可配置多个具名投递箱：

```
📥 桌面        → C:\Users\<你>\Desktop
📥 项目资料    → D:\Work\Project\素材
📥 手机相册    → 保存到系统相册（触发媒体扫描，相册里能看到）
📥 平板下载    → /storage/emulated/0/Download
📥 临时（24h） → 自动清理目录
```

发送时直接选投递箱，不用每次翻目录。🆕 **发送端可记住"发给这台设备默认用哪个投递箱"**。

### B6 🆕 拖拽与右键集成

| 平台 | 集成点 |
|---|---|
| Windows | 资源管理器右键"发送到 → ClipBridge 设备"；拖文件到托盘图标；拖到悬浮窗 |
| Windows | 🆕 **虚拟文件拖出**：从 ClipBridge 窗口把远端文件**直接拖进** Word/微信，边拖边下载（实现 `IDataObject` + `CFSTR_FILEDESCRIPTOR`，体验上等于本地文件） |
| Android | 系统分享菜单；桌面小组件；快捷设置磁贴；悬浮球；文件管理器"打开方式" |

B6 里的"虚拟文件拖出"是体验上最惊艳的一项：**远端设备上的文件，在本机看起来就像本地文件**，可以直接拖进任何应用。

### B7 🆕 远程文件浏览（可选，默认关）

授权后可浏览对端指定目录（不是全盘），按需拉取。适合"手机上想看电脑里某个文件"。

**安全**：必须显式授权具体目录（白名单），默认关闭，UI 上归入"高级功能"并有明确警示。

### B8 ✨ 文件夹传输

已在架构 §10.4。增补：
- 🆕 **增量同步模式**：第二次传同一文件夹只传变化的文件（对比 manifest 的 merkle_root）
- 🆕 **过滤规则**：`.gitignore` 风格，默认排除 `node_modules`、`.git`、`__pycache__`、`Thumbs.db`、`.DS_Store`
- 🆕 **空文件夹保留**、符号链接策略可选（跳过/转为普通文件/报错）

## C. 连接与设备

### C1 ✨ 设备组

```
我的全部设备 · 学习设备 · 办公设备 · 宿舍设备 · 临时设备
```
🆕 增强：
- 设备可属于**多个组**
- 组级权限（"办公设备组不接收私人剪贴板"）
- 组内广播发送（选组 = 选中组内所有在线设备）
- 组级密钥（用于 BLE RPA 与名单同步）

### C2 🆕 连接健康面板

这是应对 Android 后台限制的**产品化解法**：

```
连接健康度  ●●●●○  87 分
──────────────────────────
✅ 前台服务权限        已授予
✅ 电池优化            已豁免
⚠️ 自启动权限          未授予  [去设置]  ← 一键跳转厂商设置页
✅ 通知权限            已授予
✅ 局域网可达          正常
⚠️ 路由器 AP 隔离      检测到  [如何关闭]
──────────────────────────
过去 7 天在线率  96.2%
最长断连         14 分钟（7月26日 03:12，原因：系统深度睡眠）
```

**"原因"必须具体**，不能只说"连接失败"。这是用户信任的来源。

### C3 🆕 就近唤醒

对端 App 被系统冻结时，唤醒链路：

```
1. BLE 广播扫到对端 RPA → 说明设备在附近但 Wi-Fi 侧没响应 → 通过 BLE GATT 写一个 1 字节唤醒指令
2. 同局域网 → 发 UDP 唤醒包到最后已知地址
3. 都不行 → 通过服务器发高优先级 FCM data message
4. 电脑端 → 局域网 Wake-on-LAN（魔术包），可唤醒睡眠中的电脑
```

第 4 条（WoL）是个很实用的加分项：手机上点一下就能把家里睡眠的电脑叫醒并连上。

### C4 ✨ 网络模式

```
◉ 智能（局域网优先，必要时用互联网）
○ 仅局域网（完全离线可用，绝不联网）
○ 允许移动网络
   ├ 大文件仅 Wi-Fi           [开]
   ├ 移动网络单日上限          [500 MB]
   └ 移动网络仅同步文本        [开]
限速：上传 [不限] 下载 [不限] 后台 [1 MB/s]
省电模式：屏幕关闭后降低心跳频率 [开]
```

🆕 **流量统计**：按设备、按类型、按网络分别统计，让用户知道钱花哪了。

### C5 🆕 多网络并行（链路聚合）

同时有 Wi-Fi 和有线（笔记本插网线又连 Wi-Fi）时，QUIC 可在两条路径上并行传输，带宽叠加。这是 QUIC 多路径的应用，第三阶段选做。

## D. 安全与隐私

### D1 ✨ 应用锁

```
◉ 不锁（默认，直接用）
○ PIN 码
○ 密码
○ 图案
○ 生物识别（指纹/人脸）
   自动锁定：立即 / 1 分钟 / 5 分钟 / 30 分钟 / 从不
   🆕 锁定时仍保持后台同步（内容加密存储，解锁后才可见）
```

最后一条很重要：**锁应用不应该断开同步**，否则用户会因为怕断连而不设锁。做法是数据库密钥分两级——同步写入用设备密钥，查看历史需要 App 锁解密。

### D2 🆕 隐私模式（全局开关）

一键进入：
```
暂停剪贴板同步 · 不记录历史 · 通知不显示预览 · 收到的内容不落盘
```
适合"我要输密码了"或"在会议投屏"的场景。可设定时长自动恢复。

### D3 ✨ 敏感内容处理

见架构 §9.5。产品侧：
- 命中时用**黄色横幅**告知"检测到疑似验证码，已阻止自动同步 [仍要发送]"
- 用户可**训练**：标记误判 → 加入白名单（本地，不上传）
- 支持**手动标记**任意内容为敏感

### D4 🆕 安全审计日志

```
2026-07-28 14:32  设备"实验室电脑"配对成功（二维码，长期）
2026-07-28 14:35  向"荣耀平板"发送文件 report.pdf (12.4 MB)
2026-07-28 15:01  拒绝来自未知设备的连接（公钥不在信任列表）
2026-07-28 15:20  设备"临时手机"授权到期，已自动撤销
```
本地保存 90 天，可导出。这是排查"我的东西怎么发到别人那儿了"的唯一依据。

### D5 🆕 可复现构建 + 签名

安全类 App 的信任不能靠承诺。承诺：
- 全部开源
- **可复现构建**（reproducible build）：任何人用同样的源码能编译出字节相同的产物
- 发布产物带签名 + SHA-256，App 内可校验自身

**不强制注册账号，不强制给权限**。权限在真正需要时再申请（通知权限在第一次要发通知时申请，等等）。

### E6 🆕 多语言与无障碍

- 中文（简/繁）、英文；字符串外置

## G. 明确不做的事（同样重要）

| 不做 | 原因 |
|---|---|
| 无障碍服务读剪贴板 | 权限滥用，审核风险，用 IME 方案替代 |
| 自动安装收到的 APK | 安全红线 |
| 自动执行收到的 EXE/脚本 | 安全红线 |
