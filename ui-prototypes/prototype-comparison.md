> 三套方案均为独立可运行的 HTML 文件，双击即可打开，不依赖任何外部资源。

## 对比表

| 比较项目 | 方案 A · 现代简洁 | 方案 B · 专业仪表盘 | 方案 C · 自适应工作台 |
|---|---|---|---|
| **视觉风格** | Nord 系暖灰绿调，浅色舒适，卡片细边框，留白合理 | 深色侧栏+数据指标卡+图表区域，专业数据监控感 | 极简图标侧栏+三栏可调布局，面板可折叠/拖动 |
| **易用性** | 最高。侧栏文字标签全显，导航分组清晰，新手零学习成本 | 中等。信息密度高，指标丰富，适合有数据工具使用经验的用户 | 中等偏高。可折叠侧栏+左/右面板+工作区保存，需要一点适应 |
| **专业感** | 中等。简洁克制，不炫技，适合日常使用 | 最高。KPI 网格、趋势图、性能监控表、诊断页面完整 | 较高。可调面板+工作台模式，专业用户可自定义布局 |
| **信息密度** | 适中偏下。列表、卡片、区域间距宽松，适合长时间使用 | 最高。同屏可展示大量指标和数据，适合快速概览 | 可调。用户自行控制面板宽度和可见性 |
| **学习成本** | 最低。功能分类直观，命名清晰，非技术用户立刻上手 | 中等。指标含义需要一定数据素养 | 中等。面板系统需要几分钟熟悉 |
| **后续扩展** | 中等。现有结构易理解，新增页面按导航分组即可 | 高。仪表盘框架可轻松添加新指标卡和图表 | 最高。面板系统天然支持新增独立面板 |
| **小屏适配** | 好。侧栏自动收缩，面板堆叠，内容区域自适应 | 中等。深色侧栏占空间，缩小后信息密度挤压明显 | 好。可完全折叠左侧面板，右侧面板自动隐藏 |
| **大数据展示** | 中等。分页/虚拟列表/筛选器已示意 | 最强。KPI 概览+趋势图+筛选+导出完整链 | 强。分屏查看+筛选+详情面板组合 |
| **性能成本** | 最低。纯 HTML/CSS/JS，无外部依赖，无动画开销 | 中等。SVG 图表+卡片阴影，渲染略重 | 中等偏低。面板拖拽有 mousemove 监听 |
| **开发难度** | 低。直接抽取现有 shadcn/ui 样式，结构清晰 | 中等。需要实现数据指标卡和图表渲染 | 较高。需要实现面板拖拽、尺寸持久化、工作台模式 |

## 推荐默认方案

### ⭐ 推荐：方案 A（现代简洁型）

**理由：**
1. 现有项目 UI 已经使用类似风格（Nova 预设 + 暖灰底色），方案 A 是自然的延伸和优化，用户切换成本最低。
2. 非技术用户（本项目的目标用户群）最容易理解和使用。
3. 信息密度适中，长时间使用不疲劳。
4. 侧栏折叠 + 右侧详情栏已覆盖大部分专业需求。
5. 开发成本最低，可最快落地。
6. 所有创新功能（命令中心、数据健康、诊断中心、操作预览等）都可自然融入该框架。

## 下一步

1. **用户选择方案**后输出正式重构实施计划。
2. 实施计划包含：
   - 具体采用哪套方案。
   - 保留哪些现有页面和组件。
   - 新增哪些组件和页面。
   - 使用功能开关控制新界面上线。
   - 分阶段实施路线图（预计多少个 commit / PR）。
   - 测试和回滚方案。
3. 确认计划后方可开始正式 GUI 重构。
4. 正式重构前**不删除旧界面**，新界面通过功能开关控制，可随时切回。
